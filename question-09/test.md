# Question 09 — Scope & Shadowing

## Score: 9/10

### بررسی پاسخ

خروجی‌ای که نوشته شده **کاملاً صحیح است**:

```text
30
20
10
```

کد سؤال:

```js
let x = 10;

function test() {
  let x = 20;

  if (true) {
    let x = 30;
    console.log(x);
  }

  console.log(x);
}

test();

console.log(x);
```

### ❌ موردی که نیاز به تکمیل دارد

خروجی را درست تشخیص داده‌اید، اما در پاسخ باید مفهوم **Shadowing** نیز توضیح داده شود.

در این کد سه متغیر با نام `x` داریم که در Scopeهای مختلف تعریف شده‌اند.

### ✅ توضیح صحیح

```js
let x = 10;
```

این `x` در **Global Scope** قرار دارد.

داخل تابع:

```js
function test() {
  let x = 20;
}
```

یک `x` جدید تعریف شده است که متغیر Global را **Shadow** می‌کند.

یعنی داخل تابع، وقتی به `x` دسترسی پیدا می‌کنیم، JavaScript ابتدا `x` موجود در Function Scope را پیدا می‌کند:

```js
20;
```

داخل `if` نیز یک `x` جدید داریم:

```js
if (true) {
  let x = 30;
}
```

این `x` متغیر `x` موجود در Function Scope را Shadow می‌کند.

بنابراین:

```text
30 → x موجود در Block Scope
20 → x موجود در Function Scope
10 → x موجود در Global Scope
```

### نتیجه

```text
30
20
10
```

صحیح است.

**نکته:** متغیرهای `x` یکدیگر را تغییر نمی‌دهند؛ هرکدام در Scope مربوط به خودشان قرار دارند.
